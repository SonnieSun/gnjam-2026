# 大关数据

这个文件夹里每个 `.tres` 文件是一个大关，按文件名排序：`level_1.tres` 对应主菜单转盘上的第 1 格。

## 用关卡编辑器编辑（推荐）

Godot 编辑器最上面一排（2D / 3D / Script 旁边）有一个“关卡”页：

- **最上面**：选大关、新建大关、保存、试玩（从头，或者直接从选中的小关开始）。
- **左上**：这个大关里的小关，从上到下是闯关顺序。可以上下挪、复制、删除，双击打开它的场景。
- **左下**：小关场景文件夹里所有能用的场景，双击就加成一个新的小关。
- **右边**：选中小关的名字、场景、转场、积累条，以及谱子格子。
  - 先选画笔（底鼓 / 军鼓 / 踩镲 / 橡皮），左键涂，再点一下擦掉，右键擦，可以按住拖。
  - “试听”会循环播放这几小节的鼓，可以带伴奏。
  - 积累条那一行右边会显示“全中大约多少秒打满”，用来估这个小关会待多久。

换歌、换鼓声、每小节不是 16 格的谱子，这些在检查器里改（点“在检查器里打开”）。
注意：没有撤销，而且切换大关和点试玩时会自动保存。改坏了用 git 还原那个 `.tres`。

看不到“关卡”页的话，到 项目 → 项目设置 → 插件 里把 Level Editor 勾上。

## 在检查器里编辑

在 Godot 的文件面板里双击一个 `.tres`，右边的检查器里就是这个大关的全部内容，改完按 Ctrl+S 保存。

**大关本身**

| 项目 | 含义 |
|---|---|
| title | 主菜单上显示的名字 |
| look | 这一大关里 3D 小关默认的画面风格（下拉框） |
| stream | 伴奏（不带鼓的版本，循环播放） |
| bpm / beats_per_bar | 速度、每小节几拍 |
| drum_kick / snare / hat | 玩家按键时发出的鼓声 |
| rest_bars_on_switch | 每进一个小关先空几个小节再出音符 |
| sections | 小关列表，从上到下就是闯关顺序 |

**sections 里的每个小关**（点开列表里的一项）

| 项目 | 含义 |
|---|---|
| title | 小关名字（调试信息里显示） |
| scene_file | 用哪个场景。下拉框里列出了小关场景文件夹里所有能用的场景 |
| bars | 谱子。每一行是一小节，一直循环到积累条满为止 |
| beats_per_rev | 转一圈几拍 |
| transition | 切到这个小关时的转场：ZOOM 放大淡入，CUT 硬切加白闪 |
| gauge_max | 这个小关的满条值，0 = 用场景里填的或默认的 60 |
| use_gauge_events + gauge_events | 勾上后用这里填的事件分数线，比如 20、40 |

小关按积累条切换：打中加分，满条后在下一个小节线切到列表里的下一个小关，最后一个小关满条就通关。
想让某个小关待久一点，把它的 gauge_max 调大（全中时每拍 +5 分）。

## 谱子怎么写

每小节一行，一行里的字符把这一小节等分。一般写 16 个字符，也就是十六分音符的格子：

```
k...s...k...s...
```

- `k` 底鼓，`s` 军鼓，`h` 踩镲
- `.` 或别的字符是休止
- 留空的一行 = 整小节休止

想加一小节就在 bars 里加一行。

## 增减

- **加小关**：在 sections 里点“添加元素”，新建一个 SectionDef，选场景、填谱子。拖动左边的把手可以调顺序。
- **加大关**：复制一个现成的 `.tres` 改名（比如 `level_6.tres`）再改内容。主菜单场景 `scenes/menu.tscn` 里转盘上的格子也要跟着加一格。
- **加小关场景**：把 `.tscn` 放进小关场景文件夹（默认 `scenes/sections/`，可以有子文件夹），下拉框里就会出现。

两个文件夹的位置在 项目设置 → 常规 → Gnjam 里改（Sections Folder、Levels Folder）。
