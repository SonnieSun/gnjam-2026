# 大关数据

这个文件夹里每个 `.tres` 文件是一个大关，按文件名排序：`level_1_disco.tres` 对应主菜单转盘上的第 1 格，现在一共三格（`level_3_spaceship.tres` 是第 3 格）。

## 在游戏里按 Tab 编辑（阶段、镜头、猫图、音乐、谱子）

在编辑器里运行游戏，进了关卡按 **Tab**，下半屏会弹出当前小关的编辑面板（界面是英文的），再按 Tab 收起。

- **Gauge（积累条）**：最上面那根进度条。拖它 = 假装玩家把积累条打到了这么满，画面、镜头、猫图、音乐都跟着变。
  面板开着时，打中 / 漏打不再改积累条。
- **Phases（阶段）**：有些小关不靠切小关推进，而是一根很长的积累条分成很多阶段（比如迪斯科：星星灯、灯球……拆房子上路、圆台、结尾）。
  这一页列出这个小关的所有阶段线，进度条下面的小数字就是它们的位置。点一个阶段选中，可以改名字、改分数（Starts at）、删掉，
  也可以在当前进度加一条。**▶ Jump here**（或双击阶段）= 把小关重开并直接跳到那个阶段，前面的阶段会按顺序补触发。
  进度条往前拖过一条线会触发那个阶段，往回拖不会撤销（房子拆了回不去），要回去就用 Jump。
  阶段的顺序对应关卡脚本里写好的演出（第几条线演什么），所以改分数是安全的，增删会让后面的演出错位。
- **Camera（镜头）**：先把进度条拖到想要的位置，再点一个特效（3x3 Grid、Kaleidoscope、Mirror……），意思是“积累条到这里时切到它”。
  已经是它的话再点一次 = 从这里起回到原样。下面细条上的白线是切换点，拖动改位置，右键删掉。
- **Memes（猫图）**：左边是所有素材的缩略图，点一张选中，再点 “+ Add picked meme at current gauge”（或者直接双击缩略图）。
  右边的小牌子是这个小关已经放的猫图，点一下选中，然后在画面上按住拖动摆位置；
  下面可以改出现的进度（At）、大小（Size）、动效（Effect）和动效的快慢（Speed）。
  动效有：Spin 原地自转、Orbit 绕屏幕中心转圈、Stream 一排猫从右往左流过去、Bounce 跟着拍子弹、Float 上下飘。
  猫图冒出来后一直待到这个小关结束。
- **Music（音乐）**：每条轨道点一段 = 从当前进度起换成它。只有开了叠轨音乐的大关才有。
- **Pattern（谱子）**：点格子写鼓谱。改完点 “Restart stage with new pattern” 才会按新的出音符。
- **◀ ▶** 换小关，**Gauge max** 改这个小关要打多少分。

改动先只在这次运行里生效，点 **Save** 才写进文件（镜头、猫图、谱子、满条值进大关的 `.tres`，音乐进 `levels/music/` 的 `.json`）。没有撤销，改坏了别保存，按 R 重来或者用 git 还原。

加小关、调顺序、换场景在检查器里改（见下面）；加音乐轨道、加片段直接改 `levels/music/` 里的 `.json`。

## 在检查器里编辑小关列表

在 Godot 的文件面板里双击一个 `.tres`，右边的检查器里就是这个大关的全部内容，改完按 Ctrl+S 保存。

**大关本身**

| 项目 | 含义 |
|---|---|
| title | 主菜单上显示的名字 |
| look | 这一大关里 3D 小关默认的画面风格（下拉框） |
| stream | 伴奏（不带鼓的版本，循环播放） |
| bpm / beats_per_bar | 速度（现在统一 160）、每小节几拍 |
| drum_kick / snare / hat | 玩家按键时发出的鼓声 |
| rest_bars_on_switch | 每进一个小关先空几个小节再出音符 |
| sections | 小关列表，从上到下就是闯关顺序 |

**sections 里的每个小关**（点开列表里的一项）

| 项目 | 含义 |
|---|---|
| title | 小关名字（调试信息里显示） |
| scene_file | 用哪个场景。下拉框里列出了小关场景文件夹里所有能用的场景 |
| bars | 谱子。每一行是一小节，一直循环到积累条满为止 |
| beats_per_rev | 转一圈几拍 |
| transition | 切到这个小关时的转场：ZOOM 放大淡入，CUT 硬切加白闪 |
| gauge_max | 这个小关的满条值，0 = 用场景里填的或默认的 60 |
| use_gauge_events + gauge_events | 勾上后用这里填的事件分数线，比如 20、40 |

小关按积累条切换：打中加分，满条后在下一个小节线切到列表里的下一个小关，最后一个小关满条就通关。
想让某个小关待久一点，把它的 gauge_max 调大（全中时每拍 +5 分）。

## 谱子怎么写

每小节一行，一行里的字符把这一小节等分。一般写 16 个字符，也就是十六分音符的格子：

```
k...s...k...s...
```

- `k` 底鼓，`s` 军鼓，`h` 踩镲
- `.` 或别的字符是休止
- 留空的一行 = 整小节休止

想加一小节就在 bars 里加一行。

## 增减

- **加小关**：在 sections 里点“添加元素”，新建一个 SectionDef，选场景、填谱子。拖动左边的把手可以调顺序。
- **加大关**：复制一个现成的 `.tres` 改名（比如 `level_6.tres`）再改内容。主菜单场景 `scenes/menu.tscn` 里转盘上的格子也要跟着加一格。
- **加小关场景**：把 `.tscn` 放进小关场景文件夹（默认 `scenes/sections/`，可以有子文件夹），下拉框里就会出现。

两个文件夹的位置在 项目设置 → 常规 → Gnjam 里改（Sections Folder、Levels Folder）。
